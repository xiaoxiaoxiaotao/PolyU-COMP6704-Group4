COMP6704 Group 4 final report source
==================================

Main file: Group4_Report.tex
Compiler: pdfLaTeX (compile twice to resolve citations and cross-references)
Template: official NeurIPS 2025 style, supplied as neurips_2025.sty
The course-project notice is set in the main file; this is not a NeurIPS submission.

REPOSITORY LINK
---------------
The repository URL supplied by the group is included in the first-page footnote:

  https://github.com/xiaoxiaoxiaotao/PolyU-COMP6704-Group4

The URL is set by the RepositoryURL macro in Group4_Report.tex.

BUILD THE REPORT
----------------
Upload this directory to Overleaf, select Group4_Report.tex as the main document,
and choose pdfLaTeX. Alternatively, run:

  pdflatex -interaction=nonstopmode -halt-on-error Group4_Report.tex
  pdflatex -interaction=nonstopmode -halt-on-error Group4_Report.tex

No Chinese font package, BibTeX run, or external bibliography is required.
The repository copy shows author names only. Student identifiers live in a local
file named studentids.tex that git ignores: when it is present the title page
prints name plus ID (the Canvas submission build), when it is absent the build is
anonymous. No identifier ever appears in a tracked file or in git history.

REGENERATE REPORT FIGURES AND TABLES
-----------------------------------
The finished PDF figures and table fragments are included. Regeneration is optional:

  python -m pip install numpy pandas matplotlib
  python make_report_assets.py

The script reads the six archived CSV files in data/, generates three aggregate
figures, three table fragments, and aggregate_values.json. Figures and tables
come from the final archived runs, not measurements performed while drafting.

figures/archived_convergence.pdf is copied from the original project's
results/figures/main_full_convergence.pdf. It is not regenerated by this script:
the supplied archive omits the per-iteration JSON logs needed to redraw it.

DATA PROVENANCE
---------------
The following files are exact copies from the project's results/tables directory:
  correctness_runs.csv
  main_capped_runs.csv
  main_fast_runs.csv
  main_full_runs.csv
  main_full_summary.csv
  main_full_wilcoxon.csv

The completed results consist of 4 correctness fits, 36 small-workload fits,
36 medium-workload fits, and 60 full-workload fits. No incomplete stress or
ablation suite is represented as completed. The final four-solver CSV results
take precedence over preliminary three-solver tables in the original slides.

SUBMISSION PDF
--------------
The assignment asks for a single PDF named Group4.pdf, containing the report
followed by the presentation slides, with a total size below 40 MB. The separate
combined PDF supplied with this source includes the uploaded 37-page slides
after the 12-page report. The slides have not been rewritten.
After changing the repository URL or editing the report, rebuild that combined
PDF using the new report. Submit only after the group has reviewed the report.

NOTES ON SCOPE
--------------
The report records the implemented adaptive-rho ADMM baseline and distinguishes
it from the unrun fixed-rho ablation. It separates empirical target attainment
from solver-specific stopping conditions. Its reproducibility section describes
how to rerun the original project; this source package itself is a report package,
not a replacement for the original training code or transaction dataset.
